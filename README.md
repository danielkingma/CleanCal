# CleanCal

Short-term rental operations platform concept — combines the best of Breezeway and Turno (cleaning operations + cleaner marketplace) with AI quality prediction, dynamic pricing, and gamification, aimed at property managers running 50+ units.

## Contents

- `docs/CleanCal_Platform_Specification.docx` — full product specification: positioning, architecture, user roles, feature set, MVP roadmap, pricing, go-to-market, and success metrics.
- `web/index.html` — self-contained webpage version of the spec (open directly in a browser, or serve via GitHub Pages — see below).

## Viewing the webpage on GitHub Pages

Once this is pushed to GitHub:

1. Go to the repo's **Settings → Pages**.
2. Under "Build and deployment," set **Source** to "Deploy from a branch."
3. Set **Branch** to `main` and folder to `/web` (or `/root` if you move `index.html` to the repo root), then **Save**.
4. GitHub will publish it at `https://<your-username>.github.io/<repo-name>/`.
